# 六环边界与通行口 POC 报告

状态：生产拓扑与真实图复验通过，首轮人工抽查完成并保留 4 个位置，发布审批尚未完成

## 1. 结论

当前京津冀 PBF 中，北京六环的 OSM 道路编号是 `G4501`，道路关系是 `r295982`。关系成员可以合并为两条有效、闭合且互相包含的车行环线，说明可以从现有数据生成六环业务边界候选。

本轮已将边内部交叉、边端状态转换和沿边界重叠链行驶后再跨界的识别逻辑迁入生产代码。边界节点转换必须存在来源侧可达状态，并在生成候选前检查 GraphHopper 转向合法性；相同有向 edge key 和边上比例会去重，平行车道仍保持独立拓扑。

新拓扑在真实图上生成 714 条有向候选，并已直接通过单点、多方向正向/反向多目标搜索及摄像头零冲突校验。20 个高复杂度位置已完成人工抽查，16 个初步通过，`C004`、`C053`、`C060`、`C123` 作为保留项。算法已经接入正式路线接口，但当前边界仍是未批准候选；开发环境可以加载，生产环境必须启用批准门槛，不能把技术接入描述为生产发布完成。

- 已通过：边界节点状态只从来源侧可达边进入，沿边界传播和驶向目标侧前均检查单向访问及 turn costs。

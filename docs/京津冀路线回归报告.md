## 2. 异常与缓存

| 场景 | 结果 |
|---|---|
| 路网外坐标 | `OUTSIDE_ROUTING_BOUNDS` |
| 摄像头限制区起点 | `START_IN_RESTRICTED_AREA` |
| 摄像头限制区终点 | `END_IN_RESTRICTED_AREA` |
| 当前禁行快照下无合规路线 | `NO_COMPLIANT_ROUTE`：beijing-yanqing-urban-blocked、beijing-fangshan-urban-blocked |
| 相同缓存、缺少 PBF | 缓存重载成功，固定路线全部零冲突 |
| 缓存与 PBF 哈希不一致 | 启动被拒绝 |

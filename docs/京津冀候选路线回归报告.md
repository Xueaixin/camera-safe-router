## 3. 结论边界

- 本报告证明固定坐标在当前输入版本下可达并通过独立零冲突校验。
- 距离和时长是合规距离 profile 的回归基线，不代表路线质量已经人工地图验收。
- 两个真实无合规路线夹具先证明空禁行集合下可达，再证明当前禁行快照下无路。
- `NO_COMPLIANT_ROUTE` 的错误映射和无违规降级同时由确定性单元测试覆盖。

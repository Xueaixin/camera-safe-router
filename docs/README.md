## 文档更新原则

- API 字段、状态码或错误码变化时，先修改 `api-contract.yaml`，再修改前后端和测试。
- 运行路径或数据命名变化时，同步更新根 README、运行配置文档、示例环境变量和真实测试命令。
- 完成功能后立即更新开发进度，不把“代码存在”写成“用户真机验证通过”。
- 新验证报告使用中文文件名，并记录输入文件 SHA-256、命令、环境、统计和保证边界。
- `archive` 中的文件保持历史原貌，不用它们覆盖当前规范。
